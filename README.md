## What it does

`main.py` (Python 3, standard library only, no network) writes
one joke pickup line to `/output/entry.txt` — a line aimed at
a robot or an AI:

> Are you the model? I asked you to finish my sentence, and you wrote your name 214 times.

The line is 88 characters long. The joke is the machine premise
itself: the speaker asks the model to finish a sentence, and the
model answers with its own name — 214 times. The twist lands in
the final words, and there is no battery, charging or reboot joke
anywhere. One line, one twist at the end.

## How to run

```sh
python3 main.py
```

## Output

Writes one pickup line (88 characters) to `/output/entry.txt`.
Running it twice produces byte-identical output.
